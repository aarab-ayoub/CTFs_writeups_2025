# MEDCTF Writeups

This repository contains solutions and explanations for various challenges from MEDCTF, focusing on Cryptography and Reverse Engineering categories.

## 🔐 Cryptography# MEDCTF Writeups

This repository contains solutions and explanations for various challenges from MEDCTF, focusing on Cryptography and Reverse Engineering categories.

## 🔐 Cryptography

### Crypto Challenges:
- **Easy-XOR**: Solution for a basic XOR encryption challenge
- **EnigmaRot**: Walkthrough of a rotation-based cipher inspired by Enigma
- **Vowel**: Explanation of a custom vowel-based encryption algorithm
- **Warm-Up**: Entry-level crypto challenge solution

## 🔍 Reverse Engineering

### REV Challenges:
- **BabyPacking**: Analysis and unpacking of a basic packed binary
- **GuessMe**: Solution for a guessing-based reverse engineering challenge
- **Seeded**: Exploiting predictable random number generation
- **Validator**: Decompiled solution and exploitation technique

## 📁 Repository Structure

Each challenge directory contains:
- Solution scripts (`exp.py`, `exploit.c`, etc.)
- The challenge files when available
- README with detailed explanation of the approach

## 🚀 Getting Started

To use these solutions:
1. Navigate to the specific challenge directory
2. Read the README for explanation
3. Run the exploit script if you want to reproduce the solution

Feel free to contribute your own solutions or improvements!
